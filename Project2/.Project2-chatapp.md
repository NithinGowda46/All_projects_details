# 🔴 DevOps Project

This project demonstrates a complete DevOps workflow using AWS, Docker, Jenkins, Amazon ECR, Amazon EKS, Kubernetes, Argo CD, and AWS managed services.

# 🔴 AWS Services

|---|---|
| Amazon VPC | Network infrastructure |
| AWS Client VPN | Secure access to private resources |
| Amazon EC2 | CI and CD servers |
| Amazon ECR | Container image registry |
| Amazon RDS | PostgreSQL database |
| Amazon Secrets Manager | Secure application and database secrets |
| Amazon EKS | Kubernetes platform |
| EKS Auto Mode | Managed Kubernetes compute |
| Amazon CloudFront | Content delivery and application distribution |
| Amazon Route 53 | DNS management |
| AWS WAF | Web application security |
| Amazon CloudWatch | Monitoring and observability |
| AWS CloudTrail | AWS API activity and auditing |
| Amazon SNS | Notifications and alerts |
| Amazon EventBridge | Event-driven automation |
| Jenkins | Continuous Integration |
| Docker | Container image creation |
| Argo CD | Continuous Deployment |
| Kubernetes Ingress | Application traffic routing |
| HPA | Horizontal pod autoscaling |
| VPA | Vertical pod autoscaling |
| Prometheus | Metrics collection |
| Grafana | Monitoring dashboards |
